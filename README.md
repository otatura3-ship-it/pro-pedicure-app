# pro pedicure PWA — первая версия

Это статический мобильный сайт с PWA-манифестом и service worker. Он не хранит персональные данные и не создаёт отдельную систему бронирования: все реальные записи продолжают идти через DIKIDI.

## Как проверить локально
PWA-функции (service worker и установка) работают на HTTPS или localhost. Просто открытый файл `index.html` позволит проверить дизайн и ссылку на запись, но не установку.

## Публикация бесплатно
1. Создать репозиторий GitHub и загрузить файлы из этой папки.
2. В Cloudflare Pages выбрать подключение к Git-репозиторию.
3. Для статического сайта без сборки оставить build command пустым; корневая папка — `/`.
4. После публикации открыть HTTPS-ссылку на телефоне.
5. iPhone: Safari → Поделиться → На экран «Домой».
   Android: меню браузера → Установить приложение / Добавить на главный экран.

## Перед публичным запуском проверить
- Адрес и вход в кабинет.
- Актуальность списка услуг и цен в DIKIDI.
- Работу ссылки записи на iPhone и Android.
- Политику конфиденциальности, если в будущем добавятся формы сбора данных.

## Что намеренно не включено
- Личные кабинеты и база клиентов.
- Календарь/слоты бронирования.
- SMS или push-уведомления.
- Автоматическое получение услуг и цен из DIKIDI.
